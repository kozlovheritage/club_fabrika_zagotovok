# Платформа клуба «Фабрика заготовок»

Исходный код личного кабинета участников и закрытой библиотеки клуба. Основной адрес: https://platform-clubfabrika3.ru/.

## Возможности в исходном коде

- Личный кабинет и серверная авторизация; материалы доступны после проверки доступа.
- Каталог PDF, видео и аудио-материалов, включая материалы раздела «Здоровье».
- Поиск по каталогу и полнотекстовый поиск по PDF с фрагментами и страницами результатов.
- Учёт заказов и событий оплаты, обработка уведомлений Prodamus и дополнительные модули CloudPayments.
- Отправка и контроль писем с доступом, история доставки и инструменты службы заботы.
- Закрытый административный раздел для работы с заказами, платежами, письмами и поддержкой; доступ зависит от серверной настройки и роли аккаунта.
- Юридические документы и фиксация согласий.

Наличие интеграции в репозитории само по себе не означает, что провайдер включён в Production. Текущий провайдер задаётся настройкой окружения; безопасное значение по умолчанию — Prodamus. CloudPayments требует отдельного включения, подтверждённых настроек терминала и фискализации.

## Структура

- `server.mjs` — HTTP-сервер, страницы, API и проверка сессии.
- `checkout.mjs`, `prodamus-mail.mjs`, `cloudpayments*.mjs` — оформление заказа, интеграции оплаты и связанные почтовые потоки.
- `payment-history.mjs`, `history.*` — история платежей и интерфейс кабинета.
- `admin*.mjs`, `admin.html`, `admin.js`, `admin.css` — закрытые инструменты поддержки.
- `pdf-catalog.json`, `pdf-search.mjs`, `pdf-search-manifest.json` — каталог и поиск по PDF.
- `health/`, `materials/`, `start-materials/` — тексты и данные материалов.
- `legal/` — юридические документы.
- `*.test.mjs` — регрессионные тесты.
- `.env.example` и `.env.cloudpayments.example` — только имена переменных и безопасные примеры, без ключей.

## Локальный запуск

Нужны Node.js 20+ и отдельная тестовая PostgreSQL. Не подключайте локальный запуск к Production-базе и не используйте реальные ключи провайдеров для синтетических проверок.

```sh
npm install
cp .env.example .env
# заполнить локальные значения через защищённую среду
node --test
npm start
```

Сервер использует порт из `PORT`. Цены и разрешённые origin должны соответствовать продающему сайту. Не помещайте секреты в GitHub.
